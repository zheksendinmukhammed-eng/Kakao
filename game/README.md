# Кот и Рыбки 🐱🐟

Простая 2D-аркада для детей, готовая к загрузке в [Яндекс Игры](https://games.yandex.ru/console/).

## Как играть
- Кот плывёт внизу экрана. Поймай рыбку 🐟 (+1) или золотую рыбку 🐠 (+5).
- Не лови бомбы 💣 — минус жизнь ❤️ (всего 3).
- Каждые 12 очков — новый уровень, рыбки падают быстрее и чаще.
- Управление: веди кота пальцем / мышью, можно стрелками ← →. Тап/пробел — старт.

## Технически
- Чистый HTML5 + Canvas, без сборки и зависимостей.
- Управление мышью, тач-экраном и клавиатурой. Адаптив под любой размер окна и вертикальный телефон.
- Язык — русский, возраст 0+ (никакого насилия, бомба — просто мультяшный смайлик).
- Рекорд сохраняется в localStorage и отправляется в лидерборд Яндекс Игр.

## Загрузка в Яндекс Игры
1. Зарегистрируйся в [консоли разработчика Яндекс Игр](https://games.yandex.ru/console/).
2. Создай игру → черновик, добавь название, описание, иконки и скриншоты (требования по размерам консоль подскажет).
3. Заархивируй файлы игры так, чтобы **`index.html` был в корне архива**, и загрузи полученный zip как сборку.

   Пример:
   ```bash
   zip -r кот-и-рыбки.zip index.html game.js
   ```
4. Создай лидерборд в консоли с техническим названием `leaderboard` (сортировка по убыванию, целые очки).
5. Отметь игру детской (0+). Включи мобильную площадку — игра поддерживает тач.
6. Отправь на модерацию.

## SDK
Игра подключает SDK Яндекс Игр (`https://yandex.ru/games/sdk/v2`):
- `LoadingAPI.ready()` — сигнал, что игра загрузилась;
- `GameplayAPI.start()/stop()` — события начала и конца игрового процесса (нужны для показа рекламы);
- `getLeaderboards()` — отправка рекорда в лидерборд.
- Опционально запрашивается полноэкранный режим.

Вне платформы Яндекса SDK не инициализируется — игра спокойно работает локально: просто открой `index.html` в браузере.
