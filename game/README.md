# Кот-Космонавт: Космический защитник 🚀🐱

Полноценный аркадный космический шутер для детей (0+), готовый к загрузке в Yahoo… то есть в [Яндекс Игры](https://games.yandex.ru/console/).

## Что в игре
- **Экшен-геймплей**: космический кот на ракете отстреливается от 5 видов инопланетян — дроны, зигзаги, тянки-танки, стрелки и камикадзе
- **БОСС каждые 5 волн** с HP-баром, веерными и прицельными атаками
- **4 уровня оружия**: от одиночного лазера до веера из 5 стволов с тяжёлым снарядом
- **Бонусы**: монеты ★, апгрейд оружия ▲, щит ⬡, бомба ✸ (чистит весь экран), жизнь ♥
- **Комбо-система** x2–x5 за серию убийств
- **Полная векторная графика**: анимированный кот с зрачками, двигающееся пламя двигателя, туманности, параллакс-звёзды, планеты с кольцами, падающие звёзды
- **Музыка и звук**: чиптюн-саундтрек (синтезируется в WebAudio в реальном времени, без файлов) + 10 звуковых эффектов
- **Фишки на джуйс**: тряска экрана, вспышки, частицы, всплывающие очки, мигание при неуязвимости, пауза

## Управление
- Мобилки: веди пальцем — ракета летит за касанием (удобно одной рукой)
- ПК: мышь или стрелки/WASD, Space пауза-continue, Esc пауза, Enter старт
- Автострельба — игрок занимается только пилотированием

## Файлы
- `index.html` — страница (SDK Яндекса, адаптивный canvas)
- `game.js` — весь движок и контент (~52 КБ, без внешних зависимостей)
- `dist/kot-i-rybki-v1.0.zip` — готовая старая сборка (устарела)
- Сборка v2: упакуй `index.html` + `game.js` в zip (index.html в корне)

## Загрузка в Яндекс Игры
1. [Консоль разработчика](https://games.yandex.ru/console/) → черновик игры
2. Загрузи zip со сборкой (или готовый `dist/kot-i-rybki-v2.0.zip`)
3. Лидерборд с техническим названием `leaderboard` (целые очки, по убыванию)
4. Игра детская 0+, тач-управление — отмечай мобильную площадку
5. Отправка на модерацию

## Интеграция с SDK
- `LoadingAPI.ready()` — сигнал загрузки
- `GameplayAPI.start()/stop()` — для корректного показа рекламы
- Rewarded video — «Продолжить» после смерти (3 жизни назад)
- Interstitial — каждый 3-й game over
- `setLeaderboardScore('leaderboard', ...)` — рекорд в таблицу лидеров

Вне платформы Яндекса SDK игнорируется: локально игру можно просто открыть через index.html.
